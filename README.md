# Boojie Notebook

Boojie Notebook is an in-game notebook for keeping notes, checklists, and reference material close at hand in World of Warcraft.

## Features

- Account-wide and character-specific notebooks
- Dedicated Notes, Lists, and References sections
- Search across every section of the selected notebook
- Pinnable entries for quick access
- Checklists and numbered lists
- Duplicate, copy, or move entries between notebooks
- Creation and edit dates for every entry
- Movable, resizable interface with saved dimensions
- Custom fonts, font sizes, colors, backgrounds, and transparency
- Horde, Alliance, class, and BoojiePink themes
- Optional ElvUI theme matching
- Optional Bellota fonts from SharedMedia_MyMedia
- LibDataBroker minimap button with a visibility setting and WindTools compatibility

## Important

Notebook content is stored locally in World of Warcraft's SavedVariables. Include the appropriate `BoojieNotebook.lua` file from your account's `WTF` directory in your normal backups.

## Settings

Open the notebook with the minimap button, `/bn`, `/boojienotes`, or `Settings > AddOns > Boojie Notebook`. The shared `/rl` command reloads the interface.

Appearance settings are available in the notebook sidebar. You can configure the theme, font, font size, text color, background color, transparency, class-colored character names, and minimap-button visibility.

## Installation

1. Download the zip file and unarchive it.
2. Place the `BoojieNotebook` folder inside:

   `World of Warcraft/_retail_/Interface/AddOns/`

3. Ensure it is properly installed by checking:

   `World of Warcraft/_retail_/Interface/AddOns/BoojieNotebook/BoojieNotebook.toc`

4. Enable Boojie Notebook from the AddOns menu on the character-selection screen.
5. Log in or type `/reload`.
